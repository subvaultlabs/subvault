# Security Policy

We take the security of SubVault seriously. If you believe you've found a
security vulnerability, please report it to us responsibly.

## Reporting a vulnerability

Email: **info@subvault.ai**

Please include:

- A description of the issue and its potential impact.
- Steps to reproduce (minimal reproduction preferred).
- Any proof-of-concept code, screenshots, or logs.
- Your name and contact info, if you'd like to be credited.

We'll acknowledge your report within **2 business days** and keep you updated
as we investigate. Please give us reasonable time to address the issue before
public disclosure.

Thank you for helping keep SubVault and its users safe.
